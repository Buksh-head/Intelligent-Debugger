# Source Code

Use this folder for the main implementation of the prototype.

The internal structure of this folder may be adapted to suit your project architecture.

Different project types may need different folders. Teams may change the internal structure, but the repository must remain clear and easy for teaching staff to inspect.

## External Code and Libraries

If your team uses open-source code, tutorials, templates, AI-generated code, or third-party libraries, you must disclose and attribute them properly.

You must not include code that your team cannot explain.
